# `glab version`

Show version information for glab.

## Synopsis

Prints the installed glab version and the commit it was built from.
Include this information when reporting a bug.

```plaintext
glab version [flags]
```

## Aliases

```plaintext
v
```

## Examples

```console
glab version
```
