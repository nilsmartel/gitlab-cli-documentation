# `glab mr todo`

Add a to-do item to a merge request.

## Synopsis

Adding a to-do item flags the merge request for follow-up in your To-Do List.

```plaintext
glab mr todo [<id> | <branch>] [flags]
```

## Aliases

```plaintext
add-todo
```

## Examples

```console
glab mr todo 123
glab mr todo branch-name
```
